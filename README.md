# Ubuzima Health Centre.

A modern, responsive website for a **fictional** family clinic in Kigali, built with React + Vite.

**Live demo:**[ _add your Netlify/Vercel link here_](https://ubuzima-health-centre.vercel.app/)

## Features
- Responsive design (mobile menu, works on all screen sizes)
- Online booking form with validation (name, phone, service, date)
- Bookings sent to the clinic on **WhatsApp** — no backend or server costs
- Floating WhatsApp chat button
- Services, doctors, opening hours and Google Map sections
- All content in one file (`src/data.js`) — easy to reuse for any business

## Tech stack
React 18 · Vite · plain CSS (no framework)

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:5173

## Build for production
```bash
npm run build
```

## Reuse for a client
Edit `src/data.js` (name, phone, WhatsApp number, services, team, hours) and the colors at the top of `src/index.css`.
